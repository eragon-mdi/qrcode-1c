# qrcode-1c — QR-коды в 1С:Предприятии 8.1

Внешняя компонента для 1С:Предприятия 8.1 (технология COM), которая рисует QR-коды:
QR на оплату по ГОСТ Р 56042-2014 в счёте, ссылку, произвольный текст.

- **Один файл** `qrcode1c.dll`, 51 КБ, 32 бита. Windows XP SP3 – 11, в том числе 64-битные.
  Без зависимостей: не нужны ни .NET, ни Visual C++ Redistributable.
- **Без установки.** DLL кладётся в макет конфигурации или обработки. При первом вызове
  1С выгружает её во временную папку пользователя и регистрирует для него (HKCU) —
  права администратора не нужны, рабочие места настраивать не надо.
- PNG в файл или строкой base64, текст в UTF-8 или windows-1251, уровни коррекции L/M/Q/H.

> **Статус.** Компонента проверена стендом, который вызывает её так же, как 1С
> (регистрация, `IInitDone`/`ILanguageExtender`, русские имена методов, параметры по умолчанию),
> под Wine; каждый QR распознаётся декодером zbar и сверяется с исходным текстом побайтно.
> Проверка на живой 1С 8.1 идёт — результаты и проблемы пишите в Issues.

## Быстрый старт: проверка за 5 минут

1. Скачайте `qrcode1c.dll` из [Releases](../../releases) или соберите сами (см. ниже).
2. Конфигуратор → **Файл → Новый → Внешняя обработка**.
3. **Макеты → Добавить:** имя `QRCode1CDLL`, тип «Двоичные данные», загрузить `qrcode1c.dll`.
4. **Модуль объекта:** вставить целиком [`1c/QRКод.bsl`](1c/QRКод.bsl).
5. **Формы → Добавить** основную форму, в процедуру `ОсновныеДействияФормыВыполнить`
   вписать `ПоказатьПример();`.
6. Сохранить `.epf`, открыть в режиме «Предприятие», нажать «Выполнить» —
   откроется табличный документ с QR-кодом. Проверьте камерой телефона.

## В своей конфигурации

- Общий макет `QRCode1CDLL` («Двоичные данные») с `qrcode1c.dll`.
- Общий модуль `QRКод` с флагом «Клиент», текст из `1c/QRКод.bsl`;
  в функции `ДанныеКомпоненты()` заменить `ПолучитьМакет` на `ПолучитьОбщийМакет`.
- Вывод в печатную форму, где в макете есть рисунок `QR`:

```bsl
Область = Макет.ПолучитьОбласть("Шапка");
Область.Рисунки.QR.Картинка = QRКод.КартинкаQR(СтрокаДляQR);
ТабДок.Вывести(Область);
```

`КартинкаQR(Текст, РазмерМодуля = 4, Поле = 4, УровеньКоррекции = "M", Кодировка = "UTF-8")`
сама подключает компоненту, рисует PNG и возвращает `Картинка`.

## Объект `Новый("AddIn.QRCode1C")`

| Метод / свойство | |
|---|---|
| `СформироватьPNG(Текст, ИмяФайла, РазмерМодуля = 4, Поле = 4, УровеньКоррекции = "M")` | пишет PNG в файл, возвращает Булево |
| `СформироватьPNGBase64(Текст, РазмерМодуля = 4, Поле = 4, УровеньКоррекции = "M")` | PNG строкой base64; при ошибке пустая строка |
| `Кодировка` | `"UTF-8"` (по умолчанию) или `"windows-1251"` — в каких байтах текст попадёт в QR |
| `ОписаниеОшибки` | текст ошибки, если метод вернул Ложь или пустую строку |
| `Версия` | версия DLL |

`РазмерМодуля` — пикселей на один «квадратик», `Поле` — белая рамка в модулях
(по стандарту QR не меньше 4), `УровеньКоррекции` — `L`, `M`, `Q`, `H`
(QR читается при повреждении 7, 15, 25, 30% площади).

Английские имена: `GeneratePNG`, `GeneratePNGBase64`, `Encoding`, `ErrorDescription`, `Version`.

## QR на оплату (ГОСТ Р 56042-2014)

Строка — реквизиты через `|`, первым идёт заголовок `ST0001` + кодировка
(`2` — UTF-8, `1` — windows-1251, тогда и `Кодировка` компоненты ставится соответствующая):

```
ST00012|Name=ООО "Ромашка"|PersonalAcc=40702810900000000001|BankName=ПАО СБЕРБАНК|BIC=044525225|CorrespAcc=30101810400000000225|PayeeINN=7700000000|KPP=770001001|Sum=1500000|Purpose=Оплата по счету № 15 от 19.10.2026
```

Обязательны `Name`, `PersonalAcc`, `BankName`, `BIC`, `CorrespAcc` (если нет — `0`).
`Sum` — в копейках. Внутри значений не должно быть `|` и переводов строк.

## Сборка из исходников (Linux)

```sh
sudo apt install mingw-w64 mingw-w64-tools wine32 wine zbar-tools
./build.sh                    # build/qrcode1c.dll
python3 -I test/run_tests.py  # стенд под Wine + распознавание картинок zbar
```

Сборка статическая, без C++-рантайма (он тянет вызов `GetThreadId`, которого нет в XP);
импортируются только `kernel32`, `advapi32`, `msvcrt`, `oleaut32`, `shlwapi`.

## Как устроено

| Путь | Что это |
|---|---|
| `src/qrcode1c.cpp` | COM-объект: `IInitDone`, `ILanguageExtender`, саморегистрация в HKCU (и в HKLM, если 1С запущена от администратора) |
| `src/png.cpp` | PNG 1 бит/пиксель и base64, без внешних библиотек |
| `src/addin.h` | интерфейсы технологии внешних компонент 1С |
| `third_party/qrcodegen` | кодировщик QR, [Project Nayuki](https://www.nayuki.io/page/qr-code-generator-library), MIT |
| `test/` | стенд, вызывающий DLL как 1С, и сценарии с распознаванием zbar |
| `1c/QRКод.bsl` | код для 1С: подключение из макета, `КартинкаQR()`, пример |

## Ограничения

- Только Windows: на Linux-клиенте или Linux-сервере 1С COM-компоненты не загружаются.
- Только 32-битный процесс 1С. 8.1 всегда 32-битная; в 32-битных 7.7/8.2/8.3 технология
  та же и должна работать, но это не проверялось.
- DLL не подписана. Если антивирус или AppLocker блокирует загрузку из временной папки,
  добавьте исключение для `%TEMP%\qrcode1c_*.dll`.
